# كالندر حجوزات المزارع

تطبيق ويب لإدارة حجوزات تأجير مزارع في الأردن، بديل عن قوقل كالندر. مبني بـ React + Vite.

## المزايا

1. **فترتين للحجز لكل يوم**: نهارية (10ص–9م) وسهرة (10م–8ص اليوم التالي)
2. **تعدد المزارع**: كل مزرعة إلها اسم، لوكيشن، كالندر حجوزات مستقل، وأسعار مستقلة
3. **أسعار حسب أيام الأسبوع**: 3 فئات (أحد–أربعاء / خميس وسبت / جمعة)، بسعر نهاري وسهرة منفصلين لكل فئة
4. **الخصومات**: خصم بمبلغ ثابت مع سبب الخصم، والسعر النهائي يتحسب تلقائياً
5. **الدفع**: 3 طرق (نقدي، كليك، تحويل بنكي) مع تتبع المبلغ المدفوع والمتبقي
6. **بيانات الحجز**: اسم العميل، رقم الهاتف، السعر، الخصم، طريقة الدفع، ملاحظات
7. **ملخص شهري لكل مزرعة**: عدد الحجوزات، الإيرادات المتوقعة، المبالغ المتبقية

## التخزين

البيانات محفوظة بـ `localStorage` في المتصفح — تبقى بعد إغلاق الصفحة أو إعادة فتحها على نفس الجهاز والمتصفح. (ملاحظة: هذا حل من جهاز واحد فقط، لا يتزامن بين أجهزة متعددة.)

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء للنشر

```bash
npm run build
npm run preview
```

## بنية البيانات (State)

```
farms: [{ id, name, location }]
prices: { [farmId]: { day: {A, B, C}, night: {A, B, C} } }
bookings: { [farmId]: { "YYYY-MM-DD_day" | "YYYY-MM-DD_night": {
  customer, phone, base, discount, discountReason, paidAmount, method, notes
} } }
```

## أشياء ناقصة (أفكار للمرحلة الجاية)

- سعة الضيوف لكل حجز
- التفريق بين العربون والباقي
- سياسة الإلغاء
- شخص مسؤول/رقم تواصل لكل مزرعة
- أسعار خاصة للمناسبات (تتجاوز فئات الأيام العادية)
- تصدير/طباعة تقرير شهري
- قاعدة بيانات حقيقية (بدل localStorage) لو بدنا وصول من أكثر من جهاز
- حماية بسيطة (تسجيل دخول) إذا بيوصلها أكثر من موظف
